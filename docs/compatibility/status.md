# Validation status

## Verified scenarios

- **Native Windows.** On Windows 11 ARM64 with PowerShell 7.6.9 and Node.js 24.22.1, the npm package installed OpenSpec 1.16.0 and ran a real Codex 0.166.0 preview, protected apply, and no-op update. CodeGraph 1.6.2 built and served an index. One Codex session initialized OpenWiki 0.7.3 with workspace write access and the local MCP server ready before the turn. Doctor observed both tool states and passed the project build and test commands. The regression suite passed 421 tests on Windows and 437 each on macOS and Linux ARM64, with platform-specific and opt-in cases skipped.
- **Distribution.** Rigup v0.2.1 passed the release smoke checks on macOS 15 and Ubuntu 22.04 on ARM64 and x64. Its npm archive integrity matches the verified release manifest. The v0.1.0 Apple Silicon bundle also passed interactive `rigup init` and standalone MCP execution with consumer Node. [v0.2.1 release](https://github.com/ansonli-dev/rigup/releases/tag/v0.2.1) · [Release workflow run](https://github.com/ansonli-dev/rigup/actions/runs/42115711197) · [v0.1.0 evidence](https://github.com/ansonli-dev/rigup/tree/main/docs/compatibility/evidence/2026-11-05-binary-releases)
- **Codex and native tools.** Codex 0.166.0 loaded installed skills and MCP. On macOS ARM64 and clean Linux ARM64, the protected tool flow exercised pinned CodeGraph indexing, queries and recovery, OpenWiki handoff and native planning resume, and daemon cleanup. Full wiki generation is a separate task. [Tool evidence](https://github.com/ansonli-dev/rigup/tree/main/docs/compatibility/evidence/2026-11-04-native-initialization) · [Final verification](https://github.com/ansonli-dev/rigup/tree/main/docs/compatibility/evidence/2026-11-05-open-source)
- **Project E2E.** Domain-Driven Hexagon passed its scoped setup. Bulletproof React completed the semantic lifecycle, apply, no-op update, and local edit protection with **10 requests / 855,212 tokens** from its original **12 / 1,200,000** budget. Its build, 21 unit tests and three Chromium flows passed. The model run used `73442ea` and read policy 5. Policy 6 reproduced the delivered evidence in a separate equivalence audit. [Project runs](https://github.com/ansonli-dev/rigup/tree/main/docs/compatibility/evidence/2026-11-05-github-projects) · [Final E2E and usage receipts](https://github.com/ansonli-dev/rigup/tree/main/docs/compatibility/evidence/2026-11-05-open-source)
- **v0.2.1 first-run and delivery checks.** Packaged candidates set up Codex and OpenSpec on fresh Bulletproof React and Domain-Driven Hexagon checkouts. Both applied project rules while CodeGraph was serving queries, then verified a no-op update. Both rejected unapproved delivery. The React title change passed 23 unit tests and three Chromium checks. The Hexagon postal-code change passed 11 focused API tests, 12 full API tests and 12 serial Jest tests. The delivery skill completed the remaining tasks after receiving the results from the authorized test terminal.

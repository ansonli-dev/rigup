# Issue 87 · init / update 结果与下一步实施计划

> **实施代理**在控制方独立批准后使用 superpowers:subagent-driven-development 或 superpowers:executing-plans 按任务执行。复选框用于跟踪实施。

**目标**是准确显示预览、安装、前置准备和取消的结果，并保留脚本兼容性。

**结构**沿用 `runCli` 的机器报告，把显示决策留在 `createCliOutput`。OpenSpec 命令序列和原生执行效果经进程内接口进入显示层。保持批准与写入流程。

**工具**为 TypeScript、Node 24、`node:test`、tsx 及现有双语字典。

**设计**见 [Issue 87 设计与复现](../specs/2026-11-19-issue-87-design.md)。

## 评审重点

- 恢复的可执行预览可能已有部分写入，仍须使用原批准恢复（任务 1）。
- 项目目录包含空格、单引号、`&&`，或相对路径以 `-` 开头，命令必须可正确解析（任务 2）。
- 无 launcher 和真实冲突应保有实际修复入口（任务 3）。
- 重试时可能已有市场声明，或只更改宿主配置，不应撤销既有声明或把宿主状态算进项目（任务 4）。
- 写入步骤已派发但结果不可核实时，报告待核对的项目路径和不确定性（任务 4）。

# Contributing

Use [GitHub issues](https://github.com/ansonli-dev/rigup/issues) for bugs and proposals. Report vulnerabilities privately through the [security policy](SECURITY.md).

Run `npm ci`, `npm run check`, and `npm audit --audit-level=low`. The [development guide](docs/guides/development.md) lists prerequisites, focused tests, and the release checklist.

Keep changes focused and include a reproduction for behavior fixes. Explain which checks ran and record external prerequisites for skipped cases. Use sanitized fixtures and evidence. Preserve project ownership, preview and recovery contracts, research budgets, and native SDD gates.

Contributions use the [MIT License](LICENSE).

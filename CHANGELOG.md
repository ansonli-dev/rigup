# Changelog

## 0.2.3 · 2026-11-06 · Development preview

- Check the OpenSpec CLI and project entry points as soon as users select OpenSpec. With approval, install the pinned CLI and add missing native files. Resume saved choices after manual preparation.
- Apply the reviewed OpenSpec foundation in the same terminal session. Begin proposing changes with the agent as soon as initialization finishes.
- Run development through native workflow skills and project commands. Record verification in native tasks and test reports. Reuse project-owned Git hooks and configure MCP and GitLab directly.
- Preserve local configuration during updates and resume partially written native configuration. Upgrade previews identify managed launchers and scripts that can be retired.
- Verify the native MCP command from the generated agent configuration after removing the Rigup application from the portable installation.

The v0.2.2 tag stopped at portable verification. Its changes ship in v0.2.3.

[npm package](https://www.npmjs.com/package/@ansonli.dev/rigup/v/0.2.3) · [Release downloads](https://github.com/ansonli-dev/rigup/releases/tag/v0.2.3)

## 0.2.1 · 2026-11-06 · Development preview

- Default to a model-free foundation in the interactive first run. Show the pinned OpenSpec initialization command when required native entries are missing.
- Estimate the next Codex request before sending it. Preserve explicit token limits and recorded usage when continuing a research run.
- Give delivery agents runnable browser and PostgreSQL check commands with environment prerequisites. Isolate PM2 and run recognized Jest checks serially when they share a test database.
- Verify an existing CodeGraph index while its native daemon is serving it.

[npm package](https://www.npmjs.com/package/@ansonli.dev/rigup/v/0.2.1) · [Release downloads](https://github.com/ansonli-dev/rigup/releases/tag/v0.2.1)

## 0.2.0 · 2026-11-06 · Development preview

- Organize project development rules by topic. Use a bounded source survey and request additional evidence by topic when needed.
- Preview and install the base workflow with `rigup init --defer-research`. Generate and review project rules in a separate update.
- List specialized project checks with their working directories. Scope proposals to affected paths and verify callers before changing shared contracts.
- Install OpenWiki and CodeGraph in parallel after approval. Preserve operation receipts across interrupted installs.

[npm package](https://www.npmjs.com/package/@ansonli.dev/rigup/v/0.2.0) · [Release downloads](https://github.com/ansonli-dev/rigup/releases/tag/v0.2.0)

## 0.1.0 · 2026-11-05 · Development preview

- Publish the CLI as `@ansonli.dev/rigup` on the public npm registry.
- Ship portable `rigup` commands for macOS and Linux on ARM64 and x64, with an installer, SHA-256 checksums, and a compiled npm tarball.
- Guide missing choices in project-root `rigup init`. Bind the selected host and SDD to their native entry points.
- Use local Codex by default. Filter sensitive files, send evidence scoped to each generation stage, and retain usage across retries.
- Preview and apply protected updates with three-way comparison, ownership tracking, and interrupted-operation recovery.
- Install standalone skills, MCP runners, hooks, and CI checks. Initialize CodeGraph through protected staging and hand off OpenWiki generation to a separate session.
